# 🎨 Kroma Studio — UI/UX Case Studies Portal

Proyecto demostrativo desarrollado en **Laravel** para enseñar los fundamentos de ingeniería web, arquitectura **MVC** y bases de datos relacionales a estudiantes de Diseño UI/UX.

### 🛠️ Stack & Arquitectura
* **Backend:** PHP 8.x + Laravel (Rutas RESTful, Form Requests, Controladores Resource y Eloquent ORM).
* **Base de Datos:** MySQL (5 tablas relacionales: `categories`, `clients`, `projects`, `deliverables`, `testimonials`).
* **Frontend:** Motor de plantillas **Blade** (Layouts y Partials) + **Tailwind CSS**.
